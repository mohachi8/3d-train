# Tokyo Underground Spectator

東京の地下鉄の地下空間を、マイクラのスペクテイターモード風に探索できる 3D Web アプリです。山手線内を俯瞰し、その中を走る東京メトロ 9 路線と都営地下鉄 4 路線を模式的に表示します。

## 使い方

ローカルサーバーで開くのがおすすめです。

```bash
python3 -m http.server 4173
```

その後、ブラウザで `http://localhost:4173` を開いてください。

## 操作

- `探索を開始`: マウス視点操作を有効化
- `W/A/S/D`: 前後左右へ移動
- `Q/E`: 下降/上昇
- `Shift`: 高速移動
- 画面下のボタン: 全体俯瞰または主要駅へジャンプ
- 左パネルの路線チェック: 路線ごとに表示/非表示を切り替え

## モデルについて

このアプリは体験用の模式モデルです。実際の土木図面や正確な駅深度を再現したものではありません。路線色、駅の位置関係、地下階層、トンネル、連絡通路、換気塔などを「地下がどう重なっているか」を見やすくするために再構成しています。

深度は、浅い銀座線から深い大江戸線・副都心線までの傾向が見えるように、路線ごとの基準深度と駅ごとの揺らぎを入れています。交差駅では複数のホーム階層と縦方向の柱を出して、上下関係を読み取りやすくしています。
