# ADR-0001: 座標系と深度の表現

日付: 2026-06-10 / 状態: 採用

## 決定

1. **平面直角座標系IX系(JGD2011, EPSG:6677)** に投影し、東京駅付近を原点とする
   メートル単位のローカル座標(x=東, y=海抜T.P., z=南)を Three.js シーン座標とする。
2. 高さの基準は **T.P.(東京湾平均海面)**。「地表からの深さ」は表示用の派生値
   (地表標高 − トンネル標高)とする。
3. 駅間の縦断線形は **駅深度を制御点とした PCHIP(単調性保存)補間** で近似する。

## 理由

- 都心 ±20km 程度なら平面直角座標系の歪みは無視できる(スケール誤差 1/10000 級)。
  Three.js でそのままメートルが使え、ジオメトリ生成・カメラ速度の直感性が高い。
- 「深さ」は地表基準だと地形に依存して不連続になる(例: 銀座線は地表基準では浅いが
  海抜では渋谷から浅草へ向けほぼ単調に下る)。物理的に一貫する T.P. を内部表現にする。
- トンネルの実縦断は非公開。PCHIP はオーバーシュートしない(駅の間で不自然な
  山谷を作らない)ため、検証可能な情報(駅深度・交差順序)に忠実な最善近似。
- Web メルカトル(deck.gl 等の標準)を採らないのは、高緯度のスケール係数
  (東京で約1.23)が「メートル=シーン単位」の直感を壊すため。地図タイルのみ
  四隅を個別投影して歪みを吸収する。

## 影響

- アンカー(`data/registry/anchor.yaml`)の変更は全アーティファクト・共有URLを
  無効化するため禁止。
- 関東以外へ拡張する場合は系番号の切り替え機構が必要(現状スコープ外)。
